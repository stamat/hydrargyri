Below is every documentation page of the `hydrargyri` library, concatenated in full:
the API reference, the two declarative attributes, composition between elements,
and the deliberate limits.

Hydrargyri defines reactive custom elements in the light DOM — no shadow roots, no
build step, no expression language. `bind` and `on` hold names, never code, and
the markup an author wrote is what renders before, during and after the script.

Code samples are authoritative for the current release. Repository and issues:
<https://github.com/stamat/hydrargyri>. The link index for this site is at
<https://stamat.github.io/hydrargyri/llms.txt>.
